Create a modern desktop web application UI for a sustainability-focused e-commerce platform called "GreenCart".

This is a static prototype that demonstrates the concept of a sustainable online marketplace where users can discover eco-friendly products, track environmental impact, and choose green delivery options.

The design should include multiple pages connected through a clear user journey.

Use a desktop frame width of 1440px.

Design style:
Modern, clean, minimal UI with eco-friendly aesthetics.

Color palette:
Primary Green: #2E7D32
Secondary Green: #66BB6A
Light Background: #F5F7F5
Card Background: #FFFFFF
Text Color: #263238

Typography:
Use a clean sans-serif font such as Inter.

Use card-based layouts, simple icons, and clear sections.

Add placeholder images for products and simple icons for sustainability such as leaves, recycling symbols, and eco badges.

Design requirements:

Use rounded cards and soft shadows.

Keep spacing consistent.

Use icons for sustainability such as leaf, recycle, eco badge.

Ensure each page is visually simple and easy to understand.

Design should look like a real modern web application but remain simple enough to be recreated as a wireframe drawing.

Generate all pages as a connected UI system with reusable components such as navigation bars, product cards, buttons, and filters.
